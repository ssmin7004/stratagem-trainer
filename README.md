# STRATAGEM TRAINER 2.3

슈퍼 어스 전술 터미널 스타일의 스트라타젬 입력 훈련 시뮬레이터입니다.

## 2.3 변경 사항
- 선택한 스트라타젬 목록에서 문제를 무작위 추출하며 중복 출제를 허용합니다.
- 기본 훈련 문제 수는 10/20/30회 또는 직접 입력으로 설정합니다. 직접 입력은 1~9,999회입니다.
- 스트라타젬을 한 종류 이상 선택하면 문제 수와 관계없이 훈련을 시작할 수 있습니다.
- 훈련 완료 후 왼쪽 훈련 메뉴를 누르면 저장된 설정으로 다음 기본 훈련을 시작합니다.
- 결과 화면은 좌측 완료 보고, 우측 추천 설정, 하단 세부 기록으로 구성되며 세부 기록은 페이지 스크롤로 확인합니다.
- 공격/지원/방어/임무 분류색을 적용했습니다.
- NanumSquareNeo Variable WOFF2 웹폰트를 프로젝트 내부에 포함했습니다.

## 실행
1. Node.js 20 이상 설치
2. 프로젝트 폴더에서 `npm install`
3. `npm run dev`
4. 배포 빌드: `npm run build`
