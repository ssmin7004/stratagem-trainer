# STRATAGEM TRAINER 2.1

슈퍼 어스 전술 터미널 스타일의 스트라타젬 입력 훈련 웹앱입니다.

## 주요 기능
- 기본 훈련: 선택한 스트라타젬 중 무작위 10개 연속 출제 (완료 화면에서 5/10/15/20개 설정 가능)
- 연속 작전: 무작위 20개 연속 출제
- 세션 진행도 바: 스트라타젬 하나를 완료할 때마다 부드럽게 증가
- 훈련 완료 후 출제 개수 및 스트라타젬 목록 재설정
- WASD 입력, 오입력 시 현재 시퀀스 처음부터 재입력
- 경기천년 제목체 웹폰트 적용 (로컬 WOFF 파일)
- 전적과 설정은 브라우저 LocalStorage에 저장

## 실행 방법
Node.js 20 이상을 설치한 뒤 프로젝트 폴더에서 실행합니다.

```bash
npm install
npm run dev
```

배포 빌드 확인:

```bash
npm run build
```
