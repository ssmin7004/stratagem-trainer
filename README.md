# STRATAGEM TRAINER 2.2

슈퍼 어스 전술 터미널 스타일의 스트라타젬 입력 훈련 웹앱입니다.

## 주요 기능
- 기본 훈련: 선택한 스트라타젬 중 무작위 연속 출제
- 기본 훈련 개수: 10개 / 20개 / 30개 또는 직접 입력
- 연속 작전: 무작위 20개 연속 출제
- 스트라타젬 완료마다 진행도 바가 부드럽게 증가
- 훈련 완료 화면에 스트라타젬별 입력 시간과 정확도 표시
- 훈련 완료 후 다음 훈련 개수 및 출제 대상 설정
- WASD 입력, 오입력 시 현재 시퀀스 처음부터 재입력
- 경기천년 제목체 웹폰트 적용 (로컬 WOFF 파일)
- 전적 기록: 평균 입력 시간, 평균 정확도, 평균 속도 상위 스트라타젬 2개
- 전적과 설정은 브라우저 LocalStorage에 저장

## 실행 방법
Node.js 20 이상을 설치한 뒤 프로젝트 폴더에서 실행합니다.

```bash
npm install
npm run dev
```

배포 빌드 확인:

```bash
npm run build
```

## 전적 데이터 안내
기존 최고 기록은 유지됩니다. 2.2부터 새로 수집하는 완료 기록을 바탕으로 평균 입력 시간과 평균 정확도를 계산합니다. 기존 저장 데이터에는 과거 개별 시도 시간이 없으므로, 2.2 이전 시도의 평균값을 소급 계산하지 않습니다.
